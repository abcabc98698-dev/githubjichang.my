## 🚀 本地开发与构建

### 1. 克隆代码仓库
```bash
git clone https://github.com/abcabc98698-dev/githubjichang.my.git
cd githubjichang.my
```

### 2. 安装依赖项
```bash
npm install
```

### 3. 启动本地开发服务器
```bash
npm run dev
```
打开浏览器访问 [http://localhost:4321](http://localhost:4321) 即可进行实时热重载预览。

### 4. 静态编译与验证
```bash
npm run build
```
执行后会在 `dist/` 目录下生成全站纯静态 HTML、CSS、JS、Sitemap 与 Robots 文件。

### 5. 本地预览静态构建
```bash
npm run preview
```
